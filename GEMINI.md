# MiniCut

This extension adds two skills:

- `minicut-film-studio` (`skills/minicut-film-studio/SKILL.md`): installs the MiniCut CLI and makes a short film from an idea. Use it when the user wants an AI short film, AI drama, trailer, ad or music video.
- `miniapi-video` (`skills/miniapi-video/SKILL.md`): runs video, image and voice models on one MiniAPI key, with the price quoted first.

When you run `minicut setup`, run it as `MINICUT_FROM=gemini minicut setup`.
